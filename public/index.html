Moov Valuation API

Step-by-step guide to get a property valuation

1 Check API Status (Optional)

Verify all services are running before making requests.

GET /api/health
Response
{ "status": "ok", "services": { "ideal_postcodes": "ok", "property_data": "ok", "epc": "ok", "google_street_view": "ok", "supabase": "ok" } }
↓
2 Resolve Address

Send the postcode and house number. The API will look up the full address and return an id you'll use in the next step.

POST /api/address/resolve
Request Body
{ "postcode": "W14 9JH", "houseNumber": "36" }
Response
{ "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890", "postcode": "W149JH", "house_number": "36", "address_line_1": "36 Charleville Road", "address_line_2": null, "town": "London", "county": "London", "country": "England", "uprn": "34059043", "udprn": "25963057", "latitude": 51.488885, "longitude": -0.2078126, "created_at": "2025-12-03T06:10:50.526Z", "updated_at": "2025-12-03T06:10:50.526Z" }
💡 Important
Copy the id value - you need it for the valuation request. This address is now cached, so future lookups are instant and free.

Note: Postcodes are stored normalized (uppercase, no spaces) for consistent caching. You can send "W14 9JH" or "W149JH" - both work.
↓
3 Get Property Valuation

Send the addressId from Step 2, along with property details.

POST /api/valuation
Request Body (all fields required)
{ "addressId": "5cdf606b-0585-4c78-839a-6ef859e6d6d0", "addressLine1": "36 Charleville Road", "postcode": "W14 9JH", "propertyType": "flat", "saleTimeline": "8-16_weeks", "reasonForSelling": "Relocating", "source": "website", "consent": true, "hmac": "your-hmac-signature" }
Response
{ "subjectProperty": { "line_1": "36 Charleville Road", "line_2": null, "line_3": null, "post_town": "London", "postcode": "W14 9JH", "normalizedAddress": "36 Charleville Road, London, W14 9JH", "uprn": "10022866951", "coordinates": { "latitude": 51.489012, "longitude": -0.206574 } }, "epc": { "available": true, "floorAreaSqm": 48, "floorAreaSqFt": 517, "habitableRooms": 3, "rating": "C", "score": 70 }, "streetViewUrl": "https://maps.googleapis.com/maps/api/streetview?...", "streetViewAvailable": true, "marketValue": null, "offers": null, "confidence": null, "comparables": null, "timestamp": "2025-01-15T10:31:00.000Z" }
📋 Request Fields Explained
  • addressId - The id from Step 2 (required)
  • addressLine1 - Street address like "36 Charleville Road"
  • postcode - UK postcode like "W14 9JH"
  • propertyType - One of: house, flat, bungalow
  • saleTimeline - One of: 0-8_weeks, 8-16_weeks, 16+_weeks
  • reasonForSelling - Free text
  • source - Where the request came from
  • consent - Must be true
  • hmac - Security signature
