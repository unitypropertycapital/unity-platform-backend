POST /api/address/resolve

Resolve a UK address and get a unique ID for valuation. Addresses are cached - subsequent lookups are instant.

Request Body
Field Type Description
postcodeREQUIRED string UK postcode (e.g. "W14 9JH")
houseNumberREQUIRED string House number or name (e.g. "36" or "Flat 2")
Response Body
Field Type Description
id string UUID - use this as addressId in /api/valuation
postcode string Normalized postcode (no spaces, uppercase)
house_number string Normalized house number
address_line_1 string | null First line of address
address_line_2 string | null Second line of address
town string | null Town or city
county string | null County
country string Country (e.g. "England")
uprn string | null Unique Property Reference Number
udprn string | null Unique Delivery Point Reference Number
latitude number | null Latitude coordinate
longitude number | null Longitude coordinate
created_at string ISO 8601 timestamp
updated_at string ISO 8601 timestamp
📥 Example Request 
{
  "postcode": "W14 9JH",
  "houseNumber": "36"
}

  "postcode": "W149JH",
  "house_number": "36",
  "address_line_1": "36 Charleville Road",
  "address_line_2": null,
  "town": "London",
  "county": "London",
  "country": "England",
  "uprn": "34059043",
  "udprn": "25963057",
  "latitude": 51.488885,
  "longitude": -0.2078126,
  "created_at": "2025-12-03T06:10:50.526Z",
  "updated_at": "2025-12-03T06:10:50.526Z"
}
POST /api/valuation

Get comprehensive property data including EPC, Street View, and comparable sales analysis.

Request Body
Field Type Description
addressIdREQUIRED string UUID from /api/address/resolve response
addressLine1REQUIRED string Street address (e.g. "36 Charleville Road")
postcodeREQUIRED string UK postcode
propertyTypeREQUIRED string "flat" | "house" | "bungalow"
saleTimelineREQUIRED string "0-8_weeks" | "8-16_weeks" | "16+_weeks"
reasonForSellingREQUIRED string Free text reason
sourceREQUIRED string Origin identifier (e.g. "website", "app")
consentREQUIRED boolean Must be true
hmacREQUIRED string Use "placeholder" for now (HMAC coming later)
Response Body
Field Type Description
SUBJECT PROPERTY
subjectProperty.line_1 string Address line 1
subjectProperty.line_2 string | null Address line 2
subjectProperty.post_town string Town/city
subjectProperty.postcode string Postcode
subjectProperty.normalizedAddress string Full formatted address
subjectProperty.uprn string Unique Property Reference Number
subjectProperty.coordinates.latitude number Latitude
subjectProperty.coordinates.longitude number Longitude
EPC DATA
epc.available boolean Whether EPC data was found
epc.floorAreaSqm number | null Floor area in square meters
epc.floorAreaSqFt number | null Floor area in square feet
epc.habitableRooms number | null Number of habitable rooms
epc.rating string | null EPC rating (A-G)
epc.score number | null EPC score (1-100)
STREET VIEW
streetViewUrl string Google Street View image URL
streetViewAvailable boolean Whether Street View is available
COMPARABLES
comparables.radiusUsed number Search radius in miles (0.25-1.0)
comparables.radiusAttempts array Debug: comp count at each radius
comparables.totalFound number Total comps before filtering
comparables.totalKept number Comps that passed filters
comparables.totalRejected number Comps that failed filters
comparables.kept array Array of valid comparables (see schema below)
comparables.rejected array Array of rejected comparables with reasons
comparables.stats object Statistics (mean, median, etc.)
STATUS
deskReview boolean True if manual review needed (insufficient comps)
deskReviewReason string | null Reason for desk review
marketValue null Coming in Milestone 3
timestamp string ISO 8601 response timestamp
🏠 Comparable Object Schema (kept array)
FieldTypeDescription
address string Full address
postcode string Postcode
salePrice number Sale price in GBP
saleDate string Sale date (YYYY-MM-DD)
propertyType string flat | house | detached | semi-detached | terraced
floorAreaSqm number | null Floor area in sqm (null if unknown)
distanceMiles number Distance from subject in miles
pricePerSqm number | null Price per sqm (null if no floor area)
pricePerSqft number | null Price per sqft (null if no floor area)
ageMonths number Months since sale
source string "PD" (PropertyData) or "LR" (Land Registry)
❌ Rejected Object Schema (rejected array)
FieldTypeDescription
address string Full address
salePrice number Sale price in GBP
saleDate string Sale date (YYYY-MM-DD)
reason string Rejection code (see table below)
details string Human-readable explanation
Rejection Codes:
CodeMeaning
wrong_property_typeProperty type doesn't match subject
too_oldSale older than 24 months
size_mismatchFloor area differs by more than ±20%
outlier_highPrice per sqm statistically too high
outlier_lowPrice per sqm statistically too low
